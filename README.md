# تطبيق قاعدة بيانات القرآن الكريم

تطبيق متعدد المنصات (Android + Desktop) للبحث في كلمات القرآن الكريم باستخدام Flutter.

## الميزات

- 🔍 البحث في كلمات القرآن الكريم
- 📊 عرض عدد مرات ذكر الكلمة في القرآن
- 📖 عرض السورة ورقم الآية
- 💾 قاعدة بيانات محلية باستخدام SQLite
- 📱 يعمل على Android والكمبيوتر
- 🎨 واجهة مستخدم جميلة ومتجاوبة
- 🌙 دعم كامل للغة العربية

## هيكل المشروع

```
lib/
├── main.dart                    # نقطة البداية
├── models/
│   └── quran_word.dart         # نموذج البيانات
├── database/
│   └── database_helper.dart    # إدارة قاعدة البيانات
├── screens/
│   └── home_screen.dart        # الشاشة الرئيسية
└── widgets/
    └── search_dialog.dart      # نافذة النتائج المنبثقة
```

## قاعدة البيانات

يحتوي التطبيق على جدول `quran_words` بالحقول التالية:
- `id`: المعرف الفريد
- `word`: الكلمة
- `count_in_quran`: عدد مرات ذكر الكلمة في القرآن
- `surah_name`: اسم السورة
- `ayah_number`: رقم الآية

## كيفية التشغيل

### المتطلبات
- Flutter SDK
- Android Studio أو VS Code
- محاكي Android أو جهاز Android

### خطوات التشغيل

1. تأكد من تثبيت Flutter:
```bash
flutter doctor
```

2. تثبيت المكتبات:
```bash
flutter pub get
```

3. تشغيل التطبيق:
```bash
# للأندرويد
flutter run

# للكمبيوتر (Windows/Linux/macOS)
flutter run -d windows
flutter run -d linux
flutter run -d macos
```

## كيفية الاستخدام

1. افتح التطبيق
2. اكتب الكلمة التي تريد البحث عنها في حقل النص
3. اضغط على زر "بحث" أو اضغط Enter
4. ستظهر النتائج في نافذة منبثقة تحتوي على:
   - الكلمة المطابقة
   - عدد مرات ذكرها في القرآن
   - اسم السورة
   - رقم الآية

## إضافة بيانات جديدة

يمكنك إضافة المزيد من البيانات عن طريق تعديل دالة `_insertSampleData` في ملف `database_helper.dart`.
