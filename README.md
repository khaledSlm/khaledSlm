# تطبيق قاعدة بيانات القرآن الكريم

تطبيق متعدد المنصات (Android + Desktop) للبحث في كلمات القرآن الكريم باستخدام Flutter و Python.

## الميزات

- 🔍 البحث في كلمات القرآن الكريم
- 📊 عرض عدد مرات ذكر الكلمة في القرآن
- 📖 عرض السورة ورقم الآية
- 💾 قاعدة بيانات محلية باستخدام SQLite
- 📱 يعمل على Android والكمبيوتر
- 🎨 واجهة مستخدم جميلة ومتجاوبة
- 🌙 دعم كامل للغة العربية

## خيارات التشغيل

### 🐍 تطبيق Python (مُوصى به للمبتدئين)
- واجهة رسومية بسيطة باستخدام Tkinter
- سهل التثبيت والتشغيل
- يعمل على جميع أنظمة التشغيل

### 📱 تطبيق Flutter (متقدم)
- يعمل على الكمبيوتر والهاتف
- واجهة حديثة وجميلة
- أداء عالي ومتجاوب

## التشغيل السريع

### Python Application
```bash
# انقر نقراً مزدوجاً على:
start_app.bat

# أو اكتب:
python run_python_app.py
```

### Flutter Application
```bash
flutter pub get
flutter run
```

- `database_schema.sql` - مخطط قاعدة البيانات

- `run_python_app.py` - التطبيق الرئيسي Python
- `lib/` - كود تطبيق Flutter
- `start_app.bat` - ملف التشغيل السريع
